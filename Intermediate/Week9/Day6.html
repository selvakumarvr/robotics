Key Concepts

Arduino Shield Design

🛡️

Arduino Shield

A PCB that plugs directly onto Arduino Uno headers. Adds functionality without breadboard wiring

📏

Header Spacing

Arduino Uno has specific header spacing. Use "Arduino_Uno_R3" footprint from KiCad library

⬆️

Stack-able

Shields use female headers so another shield can stack on top. Height matters!

🎯

Our Shield

LED matrix + buzzer + 2 buttons + I2C connector — a useful learning shield!

Code / Reference

Arduino Shield Design — Core Skills

// Arduino Uno header pinout (for shield design):
// Digital 0-7:  J2 connector (8 pins)
// Digital 8-13: J1 connector (6 pins)
// Analog A0-A5: J3 connector (6 pins)
// Power:        J4 (Vin, GND, GND, 5V, 3.3V, RESET)

// Shield design rules:
// ✓ Use standard Arduino_Uno_R3 footprint as reference
// ✓ Board must be 68.58mm × 53.34mm for standard size
// ✓ Keep components below 15mm height for stacking
// ✓ Add ICSP header if using SPI devices
