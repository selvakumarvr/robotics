Key Concepts

Desoldering & Repair

🧵

Solder Wick

Copper braid soaked in flux. Heats up and absorbs solder through capillary action. Great for flat pads

💥

Desoldering Pump

Solder sucker — heats joint then vacuums solder away. Good for through-hole pins

🔧

Rework Station

Hot air + iron combo for professional PCB repair. Can desolder any component

♻️

Salvage

Learn to desolder components from old electronics boards — motors, displays, connectors are free!

Techniques

Desoldering & Repair

// Using solder wick:
// 1. Apply flux to the joint (helps wicking)
// 2. Lay wick over joint
// 3. Press hot iron onto wick
// 4. Hold 3-5 seconds — solder absorbed into wick
// 5. Remove wick (still hot!) then iron
// 6. Cut used section of wick off

// Using desoldering pump:
// 1. Spring/cock the pump
// 2. Heat joint with iron
// 3. Place pump nozzle over molten solder
// 4. Press button — solder sucked in
// 5. Repeat if needed
