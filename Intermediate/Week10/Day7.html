Key Concepts

Assembly Best Practices

📋

Assembly Order

1) Solder SMD first 2) Then THT short components 3) Then tall components 4) Connectors last

🔬

Stage Testing

Test at each assembly stage — find faults early before burying them under more components!

📸

Documentation

Photo each stage of build. Write build notes. Creates a build log useful for debugging

🧹

Flux Cleanup

Clean flux residue with isopropyl alcohol (IPA) — looks professional, prevents corrosion

Techniques

Assembly Best Practices

// Assembly order for a typical PCB:
// 1. SMD resistors and capacitors (lowest profile)
// 2. SMD ICs and diodes
// 3. THT resistors (bend leads first)
// 4. THT capacitors (note polarity!)
// 5. THT diodes (check cathode band direction)
// 6. ICs in DIP sockets
// 7. Tall components: inductors, transformers
// 8. Connectors and headers
// 9. Final check before power-on

// Test between stages!
