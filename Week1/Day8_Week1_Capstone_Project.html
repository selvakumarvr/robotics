Day 8 — Capstone Project

Smart Environment Monitor — What it Does

1

LDR reads light level

Continuously monitors how bright or dark the room is

2

LCD shows status

Row 1: light value. Row 2: status text (DARK / DIM / BRIGHT)

3

LED auto-brightness

Dims when bright, brightens when dark — smooth PWM

4

Servo points like a gauge

Maps light level to servo angle — acts like a light meter dial

5

Buzzer alerts on sudden dark

Short beep when light drops below DARK threshold

LDR reads light (A0)
↓
Map to LED brightness (pin 9)
↓
Map to servo angle (pin 10)
↓
if DARK → beep buzzer (pin 8)
↓
Print to LCD display
All 5 components working together in one system — this is real engineering!

Complete Wiring Plan

LDR (Light Sensor)

5V → LDR → A0 + 10kΩ → GND

LED (Auto Lamp)

Pin ~9 → 220Ω → LED(+) → LED(−) → GND

Buzzer (Alert)

Pin 8 → Piezo(+) | Piezo(−) → GND

Servo (Light Gauge)

Red→5V | Black→GND | Orange→Pin 10

LCD 16×2

RS→12, EN→11, D4→5, D5→4, D6→3, D7→2, Contrast Pot on V0

Pin summary:
// INPUTS
A0  ← LDR (light sensor)

// OUTPUTS
~9  → LED (PWM brightness)
8   → Piezo buzzer
10  → Servo signal

// LCD
12  → RS
11  → EN
5   → D4
4   → D5
3   → D6
2   → D7

Full Project Code — Part 1

#include <LiquidCrystal.h>
#include <Servo.h>

LiquidCrystal lcd(12,11,5,4,3,2);
Servo gauge;

const int ldrPin  = A0;
const int ledPin  = 9;
const int buzPin  = 8;

const int DARK   = 300;
const int DIM    = 600;
const int BRIGHT = 800;

bool lastDark = false;

void setup() {
  pinMode(ledPin, OUTPUT);
  pinMode(buzPin, OUTPUT);
  gauge.attach(10);

  lcd.begin(16, 2);
  lcd.print("Smart Monitor");
  lcd.setCursor(0,1);
  lcd.print("Starting...");
  delay(2000);
  lcd.clear();
}

Two libraries!

We include both LiquidCrystal and Servo. Arduino handles both simultaneously.

Threshold constants

DARK=300, DIM=600, BRIGHT=800. Change these to calibrate to your classroom's lighting.

lastDark variable

Tracks whether last reading was dark — so we only beep ONCE when it gets dark, not on every loop cycle.

Full Project Code — Part 2 (loop)

void loop() {
  int light = analogRead(ldrPin);

  // LED: darker = brighter
  int bright = map(light,0,1023,255,0);
  bright = constrain(bright, 0, 255);
  analogWrite(ledPin, bright);

  // Servo: maps light → angle
  int angle = map(light,0,1023,0,180);
  gauge.write(angle);

  // Buzzer: beep once on dark
  bool isDark = (light < DARK);
  if (isDark && !lastDark) {
    tone(buzPin, 800, 300);
  }
  lastDark = isDark;

  // LCD display
  lcd.setCursor(0, 0);
  lcd.print("Light:");
  lcd.print(light);
  lcd.print("     ");

  lcd.setCursor(0, 1);
  if      (light < DARK)   lcd.print("Status: DARK    ");
  else if (light < DIM)    lcd.print("Status: DIM     ");
  else if (light < BRIGHT) lcd.print("Status: MEDIUM  ");
  else                     lcd.print("Status: BRIGHT  ");

  delay(100);
}

isDark && !lastDark

This pattern detects the TRANSITION to dark (not already dark). Only beeps once when it crosses the threshold — not on every loop!

4-zone status

DARK → DIM → MEDIUM → BRIGHT. Four conditions using else if chain.

Debugging Tips — When Something Goes Wrong

LCD shows nothing

Check V0 contrast pot. Make sure lcd.begin(16,2) is in setup(). Check all 6 data pin connections.

Servo doesn't move

Check servo.attach() pin matches the signal wire. LiquidCrystal uses pins 2-5, so use pin 10 for servo.

LDR always reads same value

Make sure 10kΩ resistor is in the voltage divider (LDR leg 2 → A0 AND → 10kΩ → GND).

Buzzer keeps beeping

Check lastDark logic. The && !lastDark ensures beep only on transition, not continuous.

LED too dim or not dimming

Make sure it's on a PWM pin (~9, not 9). Check the inverted map: map(light, 0, 1023, 255, 0).

Use Serial Monitor!

Add Serial.println(light) to see what your LDR is actually reading. This is your most powerful debugging tool!

Extensions — Make It Your Own!

Add a button

Press button to mute/unmute the buzzer alarm. Use a bool muteMode variable.

Add a counter

Count how many times it's gone DARK. Show the count on the LCD row 2.

Potentiometer threshold

Use a pot on A1 to let the user manually set the DARK threshold — no code reupload needed!

Morse code LED

When it gets DARK, flash SOS in morse code with the LED instead of just turning on.

Day/Night servo labels

Servo points to labels: "NIGHT" at 0°, "SUNRISE" at 45°, "DAY" at 90°, "BRIGHT" at 180°.

Melody on dark

Instead of a single beep, play a 3-note melody from Day 4 when it gets dark.
