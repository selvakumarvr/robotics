Part 1

The LDR
Light Sensor

A resistor that changes value based on how much light hits it

LDR — Light Dependent Resistor

How it works

In bright light: low resistance (~100Ω) → lots of current flows.
In darkness: high resistance (~1MΩ) → very little current.

Voltage Divider — required!

LDR alone can't connect directly. Pair with a 10kΩ resistor to create a voltage between 0V–5V that Arduino can read.

Bright light = high reading. Dark = low reading. Yellow = LED on.

The exact threshold depends on your environment! Always use Serial Monitor to find the right value for your room.

Reading LDR & Setting a Threshold

// Step 1: find your threshold
void setup() {
  Serial.begin(9600);
}
void loop() {
  int light = analogRead(A0);
  Serial.println(light);
  delay(200);
}
Run this first! Cover the LDR with your hand, then shine a torch on it. Note the dark value and bright value — pick a threshold in the middle.
// Step 2: use the threshold
const int ldrPin = A0;
const int ledPin = 13;
const int THRESHOLD = 400;

void loop() {
  int light = analogRead(ldrPin);

  if (light < THRESHOLD) {
    digitalWrite(ledPin, HIGH);
    Serial.println("Dark - LED ON");
  } else {
    digitalWrite(ledPin, LOW);
    Serial.println("Bright - LED OFF");
  }
  delay(100);
}
Using const int THRESHOLD = 400 makes it easy to change. UPPERCASE names for constants is a common coding convention!

Part 3 — Project

Automatic
Night Lamp

Gets dark → LED turns on. Gets bright → LED turns off. All automatic!

Full Night Lamp Code

const int ldrPin  = A0;
const int ledPin  = 9;   // PWM for dim
const int THRESHOLD = 400;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int light = analogRead(ldrPin);

  // Map darkness to LED brightness
  int brightness = map(light,
    0, THRESHOLD, 255, 0);
  brightness = constrain(brightness,
    0, 255);

  analogWrite(ledPin, brightness);

  Serial.print("Light: ");
  Serial.print(light);
  Serial.print("  LED: ");
  Serial.println(brightness);

  delay(100);
}

map() — inverted this time!

map(light, 0, THRESHOLD, 255, 0) — notice the output is reversed! Less light = more brightness.

constrain(value, min, max)

Clamps a value between min and max. Prevents negative or >255 values from causing problems.

constrain(300,0,255) → 255
constrain(-5,0,255)  → 0

Smooth dimming!

Instead of just ON/OFF, the LED fades smoothly — darker room = brighter LED. Like a real smart lamp!

The 10kΩ resistor forms the lower half of the voltage divider. Without it, the pin would be floating and give random readings!

Bonus: else if — Multiple Conditions

int light = analogRead(A0);

if (light < 200) {
  // Very dark
  digitalWrite(ledPin, HIGH);
  tone(8, 500, 200);  // beep!
} else if (light < 500) {
  // Medium light
  analogWrite(ledPin, 100);
  noTone(8);
} else {
  // Bright — LED off
  digitalWrite(ledPin, LOW);
  noTone(8);
}

else if

Chain multiple conditions. Arduino checks each one in order and runs the FIRST one that's true.

3 zones of behaviour

🌑 Dark (<200): Full bright + beep
🌥 Medium (<500): Dim glow
☀️ Bright (else): LED off

New Functions This Week

map(val, fl, fh, tl, th)

Scale a value from one range to another.
map(512, 0, 1023, 0, 255) → 127

constrain(val, min, max)

Clamp a value. constrain(300, 0, 255) → 255. Prevents out-of-range errors.

analogRead(A0)

Read analog voltage on A0–A5. Returns 0–1023. No pinMode needed for analog input pins.

else if (condition)

Extend if/else to check multiple conditions. Checked in order — first true match wins.
