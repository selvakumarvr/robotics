LiquidCrystal Library — Core Functions

#include <LiquidCrystal.h>

// RS, EN, D4, D5, D6, D7
LiquidCrystal lcd(12,11,5,4,3,2);

void setup() {
  lcd.begin(16, 2);   // 16 cols, 2 rows
  lcd.print("Hello World!");
}

void loop() {
  // Move to row 1, column 0
  lcd.setCursor(0, 1);
  lcd.print("Arduino Rocks!");
  delay(2000);

  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Day 7 - LCD!");
  delay(2000);
}

LiquidCrystal lcd(12,11,5,4,3,2)

Creates the LCD object with pin numbers: RS, Enable, D4, D5, D6, D7.

lcd.begin(16, 2)

Initialise: 16 columns, 2 rows. Call this in setup() before printing.

lcd.print("text")

Prints text or a number starting at current cursor position.

lcd.clear()

Clears the entire screen and resets cursor to top-left (0,0).

setCursor() — Position Your Text

lcd.setCursor(column, row)

Column: 0–15 (left to right). Row: 0 = top, 1 = bottom.

lcd.setCursor(0, 0); // top-left
lcd.print("Light:");

lcd.setCursor(0, 1); // bottom-left
lcd.print("Temp:");

Print numbers too

int val = analogRead(A0);
lcd.setCursor(7, 0);
lcd.print(val);   // prints number

Project

Live Sensor
Dashboard!

Show LDR light value and potentiometer reading live on the LCD

Live Sensor Dashboard Code

#include <LiquidCrystal.h>

LiquidCrystal lcd(12,11,5,4,3,2);
const int ldrPin = A0;
const int potPin = A1;

void setup() {
  lcd.begin(16, 2);
  lcd.setCursor(0, 0);
  lcd.print("Sensor Dashboard");
  delay(1500);
  lcd.clear();
}

void loop() {
  int light = analogRead(ldrPin);
  int pot   = analogRead(potPin);

  // Row 0: Light reading
  lcd.setCursor(0, 0);
  lcd.print("Light:");
  lcd.print(light);
  lcd.print("    "); // clear leftovers

  // Row 1: Pot reading
  lcd.setCursor(0, 1);
  lcd.print("Pot:  ");
  lcd.print(pot);
  lcd.print("    ");

  delay(200);
}

What students will see on their LCD

Why print(" ")?

LCD doesn't auto-clear old characters. Printing spaces after the number wipes leftover digits when numbers get shorter (e.g. 1023 → 45).

No lcd.clear() in loop!

lcd.clear() causes flicker. Instead, just overwrite characters by setting the cursor position and printing new values.

Conditional Messages on LCD

int light = analogRead(A0);

lcd.setCursor(0, 0);
lcd.print("Light:");
lcd.print(light);
lcd.print("   ");

lcd.setCursor(0, 1);

if (light < 300) {
  lcd.print("Status: DARK    ");
} else if (light < 600) {
  lcd.print("Status: DIM     ");
} else {
  lcd.print("Status: BRIGHT  ");
}

LCD Function Quick Reference

lcd.begin(16,2)

Initialise 16-col, 2-row display. Must be in setup().

lcd.print(x)

Print text string or number at current cursor position.

lcd.setCursor(col, row)

Move to column (0–15) and row (0 or 1) before printing.

lcd.clear()

Wipe the whole screen. Avoid in loop() — causes flicker.

lcd.noDisplay() / display()

Turn display on/off without losing content. Like a screensaver!

lcd.blink() / noBlink()

Make the cursor blink on the screen. Good for text-entry UIs!
