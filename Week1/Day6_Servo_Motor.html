What is a Servo Motor?

Controlled rotation — not continuous!

Unlike a regular motor that just spins, a servo moves to a specific angle (0–180°) and holds there.

3 Wires

Red → 5V (power)
Black/Brown → GND
Orange/Yellow → Signal pin (any digital pin)

Real-world uses

RC car steering, robot arms, camera gimbals, door locks, drone tail rotors!

Servo angle positions:

LEFT0°
↑45°
CENTER90°
↑135°
RIGHT180°
0°
180°

Full range of motion

The servo uses a feedback mechanism (potentiometer inside) to know its current position. That's how it holds an angle precisely!

The Servo Library

// 1. Include the library
#include <Servo.h>

// 2. Create a Servo object
Servo myServo;

void setup() {
  // 3. Attach to pin 9
  myServo.attach(9);
}

void loop() {
  // 4. Move to angle
  myServo.write(0);    // 0°
  delay(1000);
  myServo.write(90);   // 90°
  delay(1000);
  myServo.write(180);  // 180°
  delay(1000);
}

#include <Servo.h>

Loads the Servo library — a built-in Arduino library. No download needed. Must be at the very top of your code.

Servo myServo

Creates a Servo object called myServo. You can call it anything! Two servos = Servo servoA, servoB.

myServo.attach(9)

Connects the servo object to pin 9. The signal wire goes here.

myServo.write(90)

Moves servo to exactly 90 degrees. Any value 0–180 is valid.

Project 1

Servo
Sweep!

Smooth back-and-forth motion — 0° to 180° and back, forever

Servo Sweep Code

#include <Servo.h>

Servo myServo;

void setup() {
  myServo.attach(9);
}

void loop() {
  // Sweep 0° → 180°
  for (int i = 0; i <= 180; i++) {
    myServo.write(i);
    delay(15);
  }

  // Sweep 180° → 0°
  for (int i = 180; i >= 0; i--) {
    myServo.write(i);
    delay(15);
  }
}

Why delay(15)?

Gives the servo time to physically move to each degree before the next command. Too fast and it stutters or skips!

Each loop step moves 1°

i goes 0→1→2…180, writing each value. 181 steps × 15ms = about 2.7 seconds for one sweep direction.

Wiring

Red → 5V | Black → GND | Orange → Pin 9. In Tinkercad: search "Servo" and it's listed in components.

Try changing delay(15) to delay(5) for fast sweep, or delay(50) for slow. See the difference!

Project 2

Pot-Controlled
Servo!

Turn the potentiometer — servo follows your hand in real time!

Potentiometer Controls Servo

#include <Servo.h>

Servo myServo;
const int potPin = A0;

void setup() {
  myServo.attach(9);
  Serial.begin(9600);
}

void loop() {
  int potVal = analogRead(potPin);

  // Map 0-1023 → 0-180 degrees
  int angle = map(potVal,
    0, 1023, 0, 180);

  myServo.write(angle);

  Serial.print("Pot: ");
  Serial.print(potVal);
  Serial.print("  Angle: ");
  Serial.println(angle);

  delay(15);
}

map(potVal, 0, 1023, 0, 180)

Scales pot's 0–1023 range to servo's 0–180 range. Pot at 512 → servo at 90°.

Direct, real-time control!

The loop runs very fast. As you turn the pot, the servo almost instantly follows — feels like a direct connection.

Wiring both components

Potentiometer: 5V, A0 (middle), GND. Servo: 5V (red), GND (black), Pin 9 (orange).

This is the same pattern used in RC cars and robot arms — a joystick or knob directly controlling a motor's position!

Bonus: Button-Controlled Servo Positions

#include <Servo.h>
Servo s;
const int btn1=2, btn2=3, btn3=4;

void setup() {
  s.attach(9);
  pinMode(btn1, INPUT_PULLUP);
  pinMode(btn2, INPUT_PULLUP);
  pinMode(btn3, INPUT_PULLUP);
}

void loop() {
  if (!digitalRead(btn1)) s.write(0);
  if (!digitalRead(btn2)) s.write(90);
  if (!digitalRead(btn3)) s.write(180);
}

3 preset positions

Button 1 = 0° (left), Button 2 = 90° (centre), Button 3 = 180° (right). Like presets on a radio!

!digitalRead(btn)

The ! means NOT. With INPUT_PULLUP, pressed = LOW = false. !false = true — so the condition triggers when pressed.

Real robotics example: each button snaps the arm to a position — like a robot arm picking up, holding, and placing objects!

Servo Library Reference

#include <Servo.h>

Load the built-in Servo library. Must be at the top of your sketch.

Servo myServo

Declare a servo object. Name it anything you like.

myServo.attach(pin)

Connect servo signal wire to a digital pin. Call this in setup().

myServo.write(angle)

Move to 0–180 degrees. The servo holds that position.

Note: The Servo library uses timer resources. When using Servo on pins 9 or 10, analogWrite() on those pins may not work — use pins 3, 5, 6, or 11 for other PWM devices.
