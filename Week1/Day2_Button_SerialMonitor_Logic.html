Part 1

The Serial
Monitor

A text window between your computer and Arduino — your debugging superpower!

What is the Serial Monitor?

The Serial Monitor is a window that lets your Arduino send text messages to your computer while it's running. It's like a walkie-talkie between your code and you!

Serial.begin(9600)

Put in setup(). Starts communication at 9600 baud (bits per second).

Serial.println("Hello!")

Prints a line of text to the monitor. println adds a new line after each message.

Serial.print(value)

Prints a value (number or variable) without jumping to a new line.

What it looks like in Tinkercad:

COM3 | 9600 baud
LED is ON
LED is OFF
LED is ON
LED is OFF
_
In Tinkercad: click "Serial Monitor" at the bottom of the screen during simulation to see output!

Serial Monitor in Code

// Serial Monitor + LED Blink
void setup() {
  Serial.begin(9600);  // start serial
  pinMode(13, OUTPUT);
  Serial.println("Arduino is ready!");
}

void loop() {
  digitalWrite(13, HIGH);
  Serial.println("LED is ON");
  delay(1000);

  digitalWrite(13, LOW);
  Serial.println("LED is OFF");
  delay(1000);
}

Why is Serial.begin() in setup()?

We only need to start the serial connection once. setup() runs once — perfect!

What's 9600?

The "baud rate" — how fast data is sent. 9600 bits per second is the standard beginner speed. Both Arduino and Monitor must match!

Printing numbers too

You can print sensor values: Serial.println(analogRead(A0));

Try it! Add a Serial.println() to your Day 1 blink code and watch the monitor!

Part 2

Variables &
Data Types

Boxes that hold information in your code — numbers, true/false, and more

Variables — Boxes for Your Data

🔢

int — Whole Numbers

Stores integers like -5, 0, 13, 255

int ledPin = 13;
✅

bool — True or False

Only two possible values: true or false

bool ledState = false;
🔒

const — Fixed Values

A variable that never changes. Good for pin numbers!

const int btnPin = 2;

Think of variables like labelled boxes:

int score = 0;
A box called "score" holding the number 0
bool isOn = false;
A box called "isOn" holding false
Rule: Always declare the type first, then the name, then the value.
type name = value;

Part 3

Push Button
Inputs

Read a button press with digitalRead() and INPUT_PULLUP

How a Push Button Works

Not Pressed = Open Circuit

The two legs are NOT connected. No current flows. Arduino reads HIGH.

Pressed = Closed Circuit

The two legs ARE connected. Current flows to GND. Arduino reads LOW.

Confusing but true: With INPUT_PULLUP, pressing the button gives you LOW, not HIGH. This is normal! The internal resistor pulls the pin HIGH when not pressed.

Wiring with INPUT_PULLUP (no external resistor needed!):

Arduino Pin 2
     ↓
Button Leg 1
     |
Button Leg 2
     ↓
Arduino GND
INPUT_PULLUP activates a built-in resistor inside the Arduino — no external 10kΩ resistor needed on the breadboard! Simpler circuit.

digitalRead() + if / else

const int btnPin = 2;
const int ledPin = 13;

void setup() {
  pinMode(btnPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int btn = digitalRead(btnPin);

  if (btn == LOW) {
    // Button IS pressed
    digitalWrite(ledPin, HIGH);
  } else {
    // Button NOT pressed
    digitalWrite(ledPin, LOW);
  }
}

digitalRead(btnPin)

Reads pin 2 — returns HIGH (1) or LOW (0) and stores it in btn.

if (btn == LOW)

If the button is pressed (LOW with INPUT_PULLUP), run the code inside { }.

else

If the condition is NOT true, run this instead. Like a fork in the road!

Hold the button → LED stays ON. Release → LED turns OFF. Simple and satisfying!

Part 4 — Project

Button-Controlled
LED Toggle!

Press once to turn ON — press again to turn OFF. A real light switch!

Full Project: Toggle LED with Button

const int btnPin = 2;
const int ledPin = 13;
bool ledState = false;   // tracks ON/OFF
bool lastBtn  = HIGH;   // last button state

void setup() {
  pinMode(btnPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  bool btn = digitalRead(btnPin);

  // Detect button press (HIGH→LOW transition)
  if (btn == LOW && lastBtn == HIGH) {
    ledState = !ledState;          // flip state
    digitalWrite(ledPin, ledState);

    if (ledState) {
      Serial.println("LED ON");
    } else {
      Serial.println("LED OFF");
    }
  }

  lastBtn = btn;  // save for next loop
  delay(50);       // debounce
}

ledState = !ledState

The ! means "NOT" — flips true to false and false to true. Like a toggle switch!

btn == LOW && lastBtn == HIGH

This detects the moment the button is pressed — not held. We only want to toggle once per press!

delay(50) — Debounce

Buttons "bounce" electrically when pressed. A 50ms delay prevents multiple triggers from a single press.

Wiring: Button between Pin 2 and GND. LED + 220Ω resistor on Pin 13 to GND. Same as Day 1 LED circuit!
