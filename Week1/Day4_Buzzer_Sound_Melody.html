Buzzer Basics & tone()

Passive Buzzer (what we use)

Needs Arduino to send a frequency — gives us control over the pitch. Wire: one leg to pin 8, other leg to GND.

tone(pin, frequency)

Plays a sound at the given frequency (Hz) until you call noTone(pin).

tone(pin, frequency, duration)

Plays for a set number of milliseconds, then stops automatically.

tone(8, 440);       // A4 note, forever
delay(500);
noTone(8);         // stop sound

// Or with duration:
tone(8, 440, 500); // play 500ms

Frequency = Pitch

NoteFrequencySounds like
C4262 HzMiddle C
D4294 HzRe
E4330 HzMi
F4349 HzFa
G4392 HzSol
A4440 HzLa (concert A)
B4494 HzSi
C5523 HzHigh C
Higher frequency = higher pitch. Lower frequency = lower pitch. The human ear hears 20 Hz to 20,000 Hz!

Arrays — Multiple Values in One Variable

An array is like a row of boxes — each box holds one value and has an index number starting from 0.

Declare an array

int melody[] = {
  262, 294, 330, 349,
  392, 440, 494, 523
}; // C D E F G A B C5

int durations[] = {
  400, 400, 400, 400,
  400, 400, 400, 800
};

Access by index

melody[0]  // → 262 (C4)
melody[1]  // → 294 (D4)
melody[7]  // → 523 (C5)

Array boxes — index starts at 0!

[0]
262
[1]
294
[2]
330
[3]
349
[4]
392

sizeof() — how many elements?

int len = sizeof(melody)
           / sizeof(melody[0]);
// gives number of notes
Always remember: first index is 0, not 1. An array of 8 items has indices 0 through 7!

Connect the negative leg to any GND pin on the Arduino.

No resistor needed for a piezo buzzer! It has high internal resistance already.

Full Melody Code

const int buzzer = 8;

// Note frequencies (C D E F G A B C5)
int melody[] = {
  262, 294, 330, 349,
  392, 440, 494, 523
};

// Duration in ms for each note
int durations[] = {
  400, 400, 400, 400,
  400, 400, 400, 800
};

void setup() {
  int len = sizeof(melody)
             / sizeof(melody[0]);

  for (int i = 0; i < len; i++) {
    tone(buzzer, melody[i], durations[i]);
    delay(durations[i] + 50); // gap
    noTone(buzzer);
  }
}

void loop() {
  // melody plays once in setup()
}

Why use setup() for the melody?

setup() runs once — perfect for a melody that plays once on startup. Move to loop() if you want it to repeat forever.

delay(durations[i] + 50)

We wait the duration PLUS 50ms extra. This creates a small gap between notes so they don't blur together.

Bonus Concept: Button Piano

Combine what you know — buttons trigger different notes!

const int btn1=2, btn2=3, btn3=4;
const int buz=8;

void setup() {
  pinMode(btn1, INPUT_PULLUP);
  pinMode(btn2, INPUT_PULLUP);
  pinMode(btn3, INPUT_PULLUP);
}

void loop() {
  if(!digitalRead(btn1)) tone(buz,262);
  else if(!digitalRead(btn2)) tone(buz,330);
  else if(!digitalRead(btn3)) tone(buz,392);
  else noTone(buz);
}
