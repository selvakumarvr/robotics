Digital vs Analog — What's the Difference?

Digital — Two States Only

Either ON (HIGH = 5V) or OFF (LOW = 0V). Nothing in between.

HIGH (5V)
LOW (0V)

Like a light switch — only two positions.

Analog — Infinite Values

Any voltage between 0V and 5V. Arduino reads this as 0–1023.

02565127681023

Like a dimmer switch — infinite positions.

🎛️

Real World Examples

Digital: On/Off button, LED state
Analog: Volume knob, temperature
Digital: Door open sensor
Analog: Light sensor, joystick
Arduino's analog pins (A0–A5) use a 10-bit ADC to measure voltage and convert it to a number from 0 (= 0V) to 1023 (= 5V).

PWM — Pulse Width Modulation

Arduino can only output 5V or 0V digitally. But by switching a pin ON and OFF very fast, it creates the effect of a voltage in between!

Duty Cycle

The % of time the pin is ON. 50% duty cycle = feels like 2.5V to the LED.

0 (0%)
OFF
64 (25%)
Dim
128 (50%)
Half
192 (75%)
Bright
255 (100%)
Full!

analogWrite(pin, value)

Sends a PWM signal to a pin. Value: 0 (fully off) to 255 (fully on).

analogWrite(9, 0);    // OFF
analogWrite(9, 128);  // 50%
analogWrite(9, 255);  // FULL
PWM pins only! Look for the ~ symbol on your Arduino board: pins ~3, ~5, ~6, ~9, ~10, ~11. These are the only pins that support analogWrite().
Analogy: Imagine flickering a light switch 500 times per second. If it's ON half the time, it looks half as bright!

for Loops — Repeat with a Counter

A for loop repeats code a set number of times, using a counter variable to track progress.

// Fade LED up — 0 to 255
for (int i = 0; i <= 255; i++) {
  analogWrite(9, i);
  delay(10);
}

// Fade LED down — 255 to 0
for (int i = 255; i >= 0; i--) {
  analogWrite(9, i);
  delay(10);
}

for loop anatomy

for (int i = 0; i <= 255; i++)
Start
i = 0
Condition
i ≤ 255
Step
i++ (+1)

i++ and i--

i++ means add 1 each time (count UP).
i-- means subtract 1 each time (count DOWN).

This loop runs 256 times — once for each brightness value. With delay(10), the full fade takes about 2.5 seconds!

Full Project Code — with map()

const int potPin = A0;  // potentiometer
const int ledPin = 9;   // PWM LED pin

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // Read pot: 0 to 1023
  int potVal = analogRead(potPin);

  // Map 0-1023 → 0-255 for LED
  int brightness = map(potVal, 0, 1023,
                            0, 255);

  analogWrite(ledPin, brightness);

  Serial.print("Pot: ");
  Serial.print(potVal);
  Serial.print("  Brightness: ");
  Serial.println(brightness);

  delay(50);
}

map(value, from_low, from_high, to_low, to_high)

Converts a number from one range to another. Here: potentiometer's 0–1023 becomes LED's 0–255.

map(512, 0, 1023, 0, 255)
→ returns 127

Why use map()?

analogRead gives 0–1023. analogWrite wants 0–255. map() scales one to fit the other automatically!
