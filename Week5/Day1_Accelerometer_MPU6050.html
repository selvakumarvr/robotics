MPU-6050 I2C Tilt Detection
Key Concepts

Accelerometer & Gyroscope

📐

6-DOF Sensing

3-axis accelerometer + 3-axis gyroscope. Detects tilt, shake, rotation, freefall

🔌

I2C Address

SDA→A4, SCL→A5. Address 0x68 (default) or 0x69 (AD0 high)

📚

MPU6050 Library

Wire.h + MPU6050 library. mpu.getAcceleration() returns ax,ay,az

🎮

Applications

Game controllers, step counters, phone screen rotation, vibration detection

Code

Accelerometer & Gyroscope — Core Code

#include <Wire.h>
#include <MPU6050.h>
MPU6050 mpu;

void setup(){
  Wire.begin(); mpu.initialize();
  Serial.begin(9600);
}
void loop(){
  int16_t ax,ay,az,gx,gy,gz;
  mpu.getMotion6(&ax,&ay,&az,&gx,&gy,&gz);
  Serial.print("AX:");Serial.print(ax/16384.0);
  Serial.print(" AY:");Serial.print(ay/16384.0);
  Serial.print(" AZ:");Serial.println(az/16384.0);
  delay(100);
}
