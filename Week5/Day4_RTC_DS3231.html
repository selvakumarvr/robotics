DS3231 RTClib Battery Backup
Key Concepts

Real-Time Clock DS3231

⏰

DS3231

Highly accurate RTC chip with I2C. Keeps time for years with a CR2032 coin battery

🔋

Battery Backup

Coin cell battery keeps time running when Arduino is off. Time persists across power cycles!

📅

Date + Time

Day, date, month, year, hours, minutes, seconds — all in one chip

🌡️

Built-in Temp

DS3231 also has a temperature sensor (±3°C accuracy) — bonus feature!

Code

Real-Time Clock DS3231 — Core Code

#include <RTClib.h>
RTC_DS3231 rtc;

void setup(){
  Wire.begin(); rtc.begin();
  // Set time once (comment out after): 
  rtc.adjust(DateTime(2025,6,1,10,30,0));
  Serial.begin(9600);
}
void loop(){
  DateTime now = rtc.now();
  Serial.print(now.hour()); Serial.print(":");
  Serial.print(now.minute()); Serial.print(":");
  Serial.println(now.second());
  delay(1000);
}
