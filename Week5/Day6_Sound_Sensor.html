Key Concepts

Sound Sensor & Music Reaction

🎤

KY-038 Module

Microphone + comparator. AO pin = analog sound level 0-1023. DO = digital threshold output

🌈

Sound Reactive

Sample sound level, map to NeoPixel brightness or colour — instant music visualiser!

🔢

Averaging

Single samples are noisy. Average 10 readings for smoother response

🎵

Beat Detection

Track peaks over time — sudden loud spike = beat detected!

Code

Sound Sensor & Music Reaction — Core Code

const int micPin = A0;
#include <FastLED.h>
CRGB leds[12];

void setup(){
  FastLED.addLeds<WS2812B,6,GRB>(leds, 12);
  FastLED.setBrightness(80);
}
void loop(){
  int raw = analogRead(micPin);
  int vol = map(raw, 0, 1023, 0, 12);
  for(int i=0;i<12;i++)
    leds[i] = (i<vol) ? CHSV(i*20,255,255) : CRGB::Black;
  FastLED.show();
}
