What is ThingSpeak?

IoT Data Platform

📊

Free IoT Platform

ThingSpeak by MathWorks stores sensor data and plots live charts. Free up to 3 million messages/year

🔑

API Keys

Each channel has a Write API Key. Include in URL to authenticate data uploads

📈

8 Fields

Each channel stores up to 8 data fields (temperature, humidity, light, etc.)

🔔

Alerts & Actions

Set thresholds to trigger email alerts or Twitter posts when sensor values cross limits

Setup

Create Your ThingSpeak Channel

1

Sign up

thingspeak.com → free account → New Channel

2

Name fields

Field 1: Temperature, Field 2: Humidity, Field 3: Light Level

3

Get API key

Channel → API Keys → copy Write API Key

4

Add to code

Paste API key into your Arduino sketch URL

5

Upload data

Run sketch, check ThingSpeak — data appears in live chart!
