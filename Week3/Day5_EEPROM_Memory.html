EEPROM Memory

What is EEPROM?

Non-Volatile Memory

💾

Non-Volatile

Electrically Erasable Programmable ROM. Data stays even when Arduino is OFF!

📏

Size

Arduino Uno has 1KB (1024 bytes) of EEPROM. Nano has 1KB, Mega has 4KB

⚠️

Write Limit

Each byte can only be written ~100,000 times. Avoid writing in fast loops!

🎯

Use Cases

High scores, calibration data, settings, user preferences, device ID

Code

Read and Write EEPROM

#include <EEPROM.h>

void setup() {
  Serial.begin(9600);

  // Write a value
  EEPROM.write(0, 42);       // address 0 = 42
  EEPROM.write(1, 255);      // address 1 = 255

  // Read it back
  byte val = EEPROM.read(0);
  Serial.println(val);       // prints 42

  // update() only writes if value changed (saves write cycles!)
  EEPROM.update(0, 100);

  // Store int (2 bytes)
  int score = 9999;
  EEPROM.put(10, score);     // auto handles multi-byte types
  int loaded;
  EEPROM.get(10, loaded);
  Serial.println(loaded);   // 9999
}
