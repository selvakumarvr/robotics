How It Works

The 7-Segment Display

🔢

7 Segments + Dot

Segments A–G + DP. Each is an LED. Light combinations form digits 0–9

🔌

Common Cathode/Anode

Common cathode: segments are HIGH for ON. Common anode: LOW for ON — check your type!

📊

Segment Map

0=abcdef, 1=bc, 2=abdeg, 3=abcdg, 4=bcfg... or use a lookup array

🔗

Multi-digit

Use transistors to switch digits on/off rapidly — persistence of vision makes all appear on

Code

Single Digit Counter

const int segs[] = {2,3,4,5,6,7,8};  // a,b,c,d,e,f,g
// digit patterns for 0-9 (a,b,c,d,e,f,g)
byte digits[10] = {
  0b0111111, // 0
  0b0000110, // 1
  0b1011011, // 2
  0b1001111, // 3
  0b1100110, // 4
  0b1101101, // 5
  0b1111101, // 6
  0b0000111, // 7
  0b1111111, // 8
  0b1101111  // 9
};

void showDigit(int n) {
  for (int i=0; i<7; i++)
    digitalWrite(segs[i], (digits[n]>>i)&1);
}

void loop() {
  for(int i=0;i<10;i++) { showDigit(i); delay(1000); }
}
