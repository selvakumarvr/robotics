How RFID Works

Radio Frequency Identification

📻

Radio Waves

RC522 emits 13.56MHz radio waves. RFID cards/tags contain a tiny antenna + chip that powers up from this field!

🆔

Unique UID

Every card has a unique 4-byte UID. Like a serial number you can read without touching or seeing the card

🔌

SPI Protocol

RC522 uses SPI (4 wires: SCK, MOSI, MISO, SS). Faster than I2C — good for security applications

📚

MFRC522 Library

Makes reading cards easy: isNewCardPresent(), readCardSerial() — two functions to get you started!

Code

Read Card UID

#include <SPI.h>
#include <MFRC522.h>

MFRC522 rfid(10, 9);  // SS pin, RST pin

void setup() {
  SPI.begin(); rfid.PCD_Init();
  Serial.begin(9600);
  Serial.println("Tap your card...");
}

void loop() {
  if (!rfid.PICC_IsNewCardPresent()) return;
  if (!rfid.PICC_ReadCardSerial()) return;

  Serial.print("UID: ");
  for (byte i=0; i<rfid.uid.size; i++) {
    Serial.print(rfid.uid.uidByte[i] < 0x10 ? " 0" : " ");
    Serial.print(rfid.uid.uidByte[i], HEX);
  }
  Serial.println();
  rfid.PICC_HaltA();
}
Project

RFID Door Lock

1️⃣

Step 1: Get your card UID

Run the basic read sketch, tap your card, note down the UID bytes

2️⃣

Step 2: Store allowed UIDs

Create a byte array with your card's UID: byte allowedUID[] = {0xAB, 0xCD, ...};

3️⃣

Step 3: Compare UIDs

Loop through bytes — if all match, grant access (green LED + servo). Otherwise deny!

4️⃣

Step 4: Add LCD feedback

"WELCOME!" or "ACCESS DENIED" displayed on LCD when card is tapped
