NeoPixel LED Strip

Programmable RGB LEDs — one wire controls them all!

FastLED / Adafruit NeoPixel RGB Colour Control Animations
What are NeoPixels?

WS2812B Addressable LEDs

🌈

Full RGB

Each LED has Red, Green, Blue 0–255. Mix any colour — 16 million possibilities!

🔗

Chainable

One data wire controls hundreds of LEDs. Each LED passes data to the next

⚡

Power Warning

Each NeoPixel at full white draws 60mA. 60 LEDs = 3.6A! Use external 5V supply for long strips

📚

FastLED Library

FastLED or Adafruit_NeoPixel — both work great. FastLED has more animation tools

Code

Colour Chase Animation

#include <FastLED.h>
#define NUM_LEDS 12
#define DATA_PIN 6
CRGB leds[NUM_LEDS];

void setup() {
  FastLED.addLeds<WS2812B,DATA_PIN,GRB>(leds, NUM_LEDS);
  FastLED.setBrightness(50);  // 0-255
}

void loop() {
  // Rainbow chase
  for(int i=0; i<NUM_LEDS; i++) {
    leds[i] = CHSV(i*255/NUM_LEDS, 255, 255);  // HSV hue
  }
  FastLED.show();
  delay(50);
  // Rotate by shifting hue
  static uint8_t hue = 0;
  for(int i=0; i<NUM_LEDS; i++)
    leds[i] = CHSV(hue + i*10, 255, 255);
  hue++; FastLED.show(); delay(20);
}
