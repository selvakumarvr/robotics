The Science

How Infrared Remote Control Works

📡

Invisible Light

IR remotes send flashes of infrared light at 38kHz — too fast to see but the receiver can detect it

🔢

Binary Codes

Each button press sends a unique pattern of on/off pulses that encodes a number (like Morse code!)

🧮

HEX Numbers

Arduino decodes the pulse pattern into a hexadecimal number. Each button = unique HEX code

🎮

TSOP1738 Receiver

3-pin component: VCC (3.3V!), GND, and Signal. Filters noise and outputs clean digital signal

Step 1

Find Your Remote's HEX Codes

Every remote is different — first decode your buttons!

// Sketch 1: Decode remote buttons
#include <IRremote.h>

const int recvPin = 11;
IRrecv irrecv(recvPin);
decode_results results;

void setup() {
  Serial.begin(9600);
  irrecv.enableIRIn();
  Serial.println("Waiting for IR signal...");
}

void loop() {
  if (irrecv.decode(&results)) {
    Serial.print("HEX Code: 0x");
    Serial.println(results.value, HEX);
    irrecv.resume();  // Ready for next signal
  }
}

Upload this sketch, open Serial Monitor at 9600, press each button on your remote — note down the HEX codes! Write them on paper.

Code

Remote-Controlled LEDs with switch/case

#include <IRremote.h>
const int recvPin=11, redLed=4, greenLed=5, blueLed=6;
IRrecv irrecv(recvPin);
decode_results results;

void setup() {
  irrecv.enableIRIn();
  pinMode(redLed, OUTPUT); pinMode(greenLed, OUTPUT); pinMode(blueLed, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  if (irrecv.decode(&results)) {
    if (results.value != 0xFFFFFFFF) {  // Ignore repeat
      switch (results.value) {
        case 0xFFA25D:  // Button 1
          digitalWrite(redLed, !digitalRead(redLed));
          Serial.println("RED toggle"); break;
        case 0xFF629D:  // Button 2
          digitalWrite(greenLed, !digitalRead(greenLed));
          Serial.println("GREEN toggle"); break;
        case 0xFFE21D:  // Button 3
          digitalWrite(blueLed, !digitalRead(blueLed));
          Serial.println("BLUE toggle"); break;
        case 0xFF38C7:  // OK - all off
          digitalWrite(redLed, LOW); digitalWrite(greenLed, LOW); digitalWrite(blueLed, LOW);
          Serial.println("ALL OFF"); break;
      }
    }
    irrecv.resume();
  }
}
New Concept

switch / case — Cleaner than if/else!

What is switch/case?

A cleaner way to compare one variable against many values. Like a vending machine — match the number, get the result!

break is important!

Without break, code "falls through" to the next case. Always end each case with break;

default case

Add default: at the end to handle unknown values — like an "else" for switch

vs if/else

switch/case is cleaner when checking ONE variable against MANY values. Use if/else for complex conditions (ranges, >, <)
