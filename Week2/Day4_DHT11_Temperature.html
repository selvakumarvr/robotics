The Sensor

Meet the DHT11

🌡️

Temperature

Measures from 0°C to 50°C with ±2°C accuracy. Good for indoor environments!

💧

Humidity

Measures relative humidity from 20% to 90% with ±5% accuracy

🔌

Only 3 Pins

VCC (3.3V or 5V), GND, and a single data pin. Uses its own serial protocol!

📦

DHT Library

The DHT library handles all the complex communication. Just call dht.readTemperature()!

Wiring

DHT11 Connections

Only 3 wires needed!

DHT11 PinArduinoNotes
VCC (Pin 1)5VPower supply
DATA (Pin 2)Digital Pin 2Add 10kΩ pull-up to 5V
NC (Pin 3)—Not connected
GND (Pin 4)GNDGround

💡 Most DHT11 modules (on a breakout board) have only 3 pins and the pull-up resistor built in — just VCC, DATA, GND. Much easier!

New Concept

float — Numbers with Decimal Points

int vs float

int temp = 23; — whole numbers only
float temp = 23.5; — decimals allowed!

Memory

int = 2 bytes. float = 4 bytes. Floats use more memory but handle sensor readings perfectly

NaN check!

DHT can fail to read. Always check: if (isnan(temp)) before using the value

Printing floats

Serial.print(temp, 1) — prints with 1 decimal place. Default is 2 decimal places

Code

Reading Temperature & Humidity

#include <DHT.h>

#define DHTPIN 2
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
  Serial.println("DHT11 Ready!");
}

void loop() {
  delay(2000);  // DHT11 needs 2 sec between readings

  float humidity = dht.readHumidity();
  float tempC = dht.readTemperature();
  float tempF = dht.readTemperature(true); // true = Fahrenheit

  if (isnan(humidity) || isnan(tempC)) {
    Serial.println("Read failed!");
    return;
  }

  Serial.print("Temp: "); Serial.print(tempC); Serial.println("°C");
  Serial.print("Humidity: "); Serial.print(humidity); Serial.println("%");
}
Project

Temperature Dashboard on LCD

#include <DHT.h>
#include <LiquidCrystal.h>

DHT dht(2, DHT11);
LiquidCrystal lcd(12,11,5,4,3,2);  // adjust pins as needed
// Note: DHT uses pin 7 if LCD uses pin 2

void setup() {
  lcd.begin(16, 2);
  dht.begin();
  lcd.print("Weather Station");
  delay(2000); lcd.clear();
}

void loop() {
  float h = dht.readHumidity();
  float t = dht.readTemperature();
  if (!isnan(t) && !isnan(h)) {
    lcd.setCursor(0, 0);
    lcd.print("Temp: "); lcd.print(t, 1); lcd.print(" C  ");
    lcd.setCursor(0, 1);
    lcd.print("Hum:  "); lcd.print(h, 1); lcd.print(" %  ");
    // Comfort indicator
    if (t > 28) { lcd.setCursor(14,0); lcd.print("!!"); }
  }
  delay(2000);
}
