The Module

HC-05 Bluetooth Module

📶

Bluetooth 2.0

Classic Bluetooth, pairs with phones and computers. Range ~10 metres

💬

Serial Communication

Works like a wireless serial port. Data sent from phone appears as Serial characters on Arduino!

⚠️

Voltage Warning

HC-05 RX pin works at 3.3V logic. Use a voltage divider (1kΩ + 2kΩ) on Arduino TX → HC-05 RX

📱

Phone App

Use "Serial Bluetooth Terminal" (Android) or "Bluetooth Terminal" app to send commands

Wiring

HC-05 + SoftwareSerial

💡 SoftwareSerial lets you use any 2 digital pins as a serial port, freeing up pins 0/1 (hardware serial) for the Serial Monitor. Essential when using HC-05!

Setup

Pairing Your Phone

1

Power up HC-05

LED should blink fast (2x/sec) = not paired. Slow blink (1x/2sec) = paired

2

Phone Bluetooth Settings

Scan for devices → find "HC-05" → tap to pair → PIN is 1234 (default)

3

Install App

Download "Serial Bluetooth Terminal" on Android or "BlueSee" on iOS

4

Connect in App

Open app → select HC-05 → set baud rate to 9600 → Connected! LED stays on

5

Send a command

Type '1' and send. Arduino should respond!

Code

Bluetooth-Controlled LED

#include <SoftwareSerial.h>

SoftwareSerial bt(10, 11);  // RX=10, TX=11
const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
  bt.begin(9600);
  Serial.begin(9600);
  Serial.println("Bluetooth Ready!");
}

void loop() {
  if (bt.available()) {
    char cmd = bt.read();  // Read one character
    Serial.print("Got: "); Serial.println(cmd);

    if (cmd == '1') {
      digitalWrite(ledPin, HIGH);
      bt.println("LED ON");
    } else if (cmd == '0') {
      digitalWrite(ledPin, LOW);
      bt.println("LED OFF");
    }
  }
}
