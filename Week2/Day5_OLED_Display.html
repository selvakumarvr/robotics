OLED vs LCD

Why OLED is Awesome

🖤

True Black

OLED pixels turn completely off for black — perfect contrast, no backlight needed

🔌

Only 2 Wires!

Uses I2C protocol — just SDA and SCL pins. LCD needs 6+ wires. HUGE wiring advantage!

🎨

Draw Anything

Draw pixels, lines, circles, rectangles, bitmaps — full graphics capability!

📐

128 × 64 pixels

128 columns × 64 rows of pixels. Small but crisp! I2C address: 0x3C (most common)

Wiring

I2C — The 2-Wire Protocol

OLED PinArduino UnoNotes
VCC3.3V or 5VCheck your module's voltage!
GNDGNDCommon ground
SDAA4 (Pin 18)I2C Data line
SCLA5 (Pin 19)I2C Clock line

💡 I2C (eye-squared-C) is a 2-wire bus where multiple devices share SDA+SCL. Each device has a unique address (OLED = 0x3C). You can chain multiple I2C devices on the same 2 wires!

Setup

Installing the Libraries

1

Adafruit SSD1306

Arduino IDE → Sketch → Include Library → Manage Libraries → Search "SSD1306" → Install "Adafruit SSD1306"

2

Adafruit GFX Library

Also install "Adafruit GFX Library" — it's the graphics engine that SSD1306 depends on

3

Wire Library

Already built into Arduino — handles I2C communication automatically

4

Tinkercad Note

Tinkercad doesn't support OLED natively — use the Arduino IDE with a real OLED, or use Wokwi.com (free online simulator with OLED support!)

Code

Hello World on OLED

#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

#define SCREEN_WIDTH 128
#define SCREEN_HEIGHT 64
Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);

void setup() {
  display.begin(SSD1306_SWITCHCAPVCC, 0x3C);
  display.clearDisplay();
  display.setTextSize(2);          // Font size (1, 2, 3...)
  display.setTextColor(WHITE);
  display.setCursor(10, 20);       // x, y pixel position
  display.println("Hello!");
  display.display();               // Send buffer to screen!
}

void loop() { }

⚠️ Always call display.display() after drawing! All drawing commands write to a buffer in RAM. display() sends the buffer to the screen.

Graphics

Drawing Shapes & Graphics

// Draw a rectangle
display.drawRect(10, 10, 50, 30, WHITE);  // x,y,w,h,color
display.fillRect(70, 10, 50, 30, WHITE);  // Filled!

// Draw a circle
display.drawCircle(64, 32, 20, WHITE);   // x,y,radius,color
display.fillCircle(20, 50, 10, WHITE);

// Draw a line
display.drawLine(0, 0, 127, 63, WHITE); // x0,y0,x1,y1

// Draw a progress bar
int progress = 75;  // 0–100%
display.drawRect(0, 54, 128, 10, WHITE);
display.fillRect(0, 54, progress * 128 / 100, 10, WHITE);

display.display();  // Don't forget!
Project

Sensor Dashboard on OLED

📡

What to Display

Show potentiometer value as a progress bar + number, and a button status indicator

🔄

Update Loop

clearDisplay() → draw all elements → display() every 100ms for smooth updates

🎨

Layout Tips

Top area: title text (size 1). Middle: big value (size 2–3). Bottom: progress bar. Keep it clean!

⚡

Performance

Full screen update takes ~20ms. For fast animations, only redraw changed areas using fillRect to erase old values
