The Problem

Why Can't Arduino Drive a Motor Directly?

⚡

Arduino Pin Limit

Each Arduino pin can only supply 40mA max. A DC motor needs 200mA–1A to run!

🔄

Direction Problem

Arduino can only output HIGH or LOW (one direction). Motors need to go forwards AND backwards.

🛡️

The Solution: L298N

The L298N motor driver takes Arduino's logic signals and controls a separate power supply for the motors.

🤖

Used Everywhere!

Every robot car uses a motor driver. Master this and you can build any wheeled robot!

H-Bridge

How the H-Bridge Works

Named after the "H" shape of its circuit diagram

Forward

➡️

IN1=HIGH, IN2=LOW

Current flows left → right through motor

Backward

⬅️

IN1=LOW, IN2=HIGH

Current flows right → left through motor

Stop (Brake)

⏹️

IN1=HIGH, IN2=HIGH

Motor brakes (both sides connected)

Coast (Free)

💨

IN1=LOW, IN2=LOW

Motor coasts to a stop freely

ENA pin = Enable + Speed control. Use analogWrite(ENA, 0-255) to set motor speed!

Code

Controlling a DC Motor

const int in1 = 4;
const int in2 = 5;
const int ena = 3;  // PWM pin

void setup() {
  pinMode(in1, OUTPUT);
  pinMode(in2, OUTPUT);
  pinMode(ena, OUTPUT);
}

void loop() {
  // Forward at full speed
  digitalWrite(in1, HIGH);
  digitalWrite(in2, LOW);
  analogWrite(ena, 255);   // Full speed
  delay(2000);

  // Slow down
  analogWrite(ena, 100);   // Half speed
  delay(2000);

  // Backward
  digitalWrite(in1, LOW);
  digitalWrite(in2, HIGH);
  analogWrite(ena, 200);
  delay(2000);

  // Stop
  analogWrite(ena, 0);
  delay(1000);
}

Project Code

Pot-Controlled Motor Speed

Map potentiometer (0–1023) to motor speed and direction

const int potPin = A0;
const int in1=4, in2=5, ena=3;

void setup() {
  pinMode(in1, OUTPUT); pinMode(in2, OUTPUT); pinMode(ena, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int potVal = analogRead(potPin);  // 0–1023

  if (potVal < 412) {
    // Left half → reverse, faster as you turn left
    digitalWrite(in1, LOW); digitalWrite(in2, HIGH);
    int spd = map(potVal, 412, 0, 0, 255);
    analogWrite(ena, spd);
  } else if (potVal > 612) {
    // Right half → forward, faster as you turn right
    digitalWrite(in1, HIGH); digitalWrite(in2, LOW);
    int spd = map(potVal, 612, 1023, 0, 255);
    analogWrite(ena, spd);
  } else {
    // Middle zone → stop
    analogWrite(ena, 0);
  }
  Serial.println(potVal);
  delay(50);
}
Going Further

Two Motors — Robot Chassis!

🔌

L298N has 2 channels

IN1/IN2 + ENA = Motor A. IN3/IN4 + ENB = Motor B. Control two motors independently!

➡️

Move Forward

Both motors forward → robot goes straight

↩️

Turn Left

Right motor forward, left motor stop (or reverse)

↪️

Turn Right

Left motor forward, right motor stop (or reverse)

This is exactly what your Week 2 Capstone obstacle-avoiding robot will use! We'll add the ultrasonic sensor from Day 1 to navigate automatically.
