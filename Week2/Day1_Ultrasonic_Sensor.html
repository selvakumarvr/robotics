The Science

How Ultrasonic Sensors Work

Like a bat using echolocation!

📡

1. Send a ping

The TRIG pin sends an ultrasonic pulse (40,000 Hz — too high for humans to hear)

🔁

2. Wait for echo

The sound bounces off an object and returns to the ECHO pin

⏱️

3. Measure time

Arduino measures how long the round trip took in microseconds

📏

4. Calculate distance

Speed of sound = 343 m/s → divide duration by 58.2 to get centimetres

distance (cm) = duration (µs) ÷ 58.2
HC-SR04

Wiring the Ultrasonic Sensor

4 pins, easy to connect

HC-SR04 PinArduino PinDescription
VCC5VPower supply
GNDGNDGround
TRIGDigital Pin 9Send trigger pulse (OUTPUT)
ECHODigital Pin 10Receive echo pulse (INPUT)
💡

Important!

The HC-SR04 ECHO pin outputs 5V but some boards are 3.3V. For Arduino Uno it's fine. In Tinkercad, just connect it directly — it works perfectly for simulation.

Code

Reading Distance — Basic Code

const int trigPin = 9;
const int echoPin = 10;
long duration;
float distanceCm;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  Serial.begin(9600);
}

void loop() {
  // Send 10µs trigger pulse
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  // Measure echo time in microseconds
  duration = pulseIn(echoPin, HIGH);

  // Convert to centimetres
  distanceCm = duration / 58.2;

  Serial.print("Distance: ");
  Serial.print(distanceCm);
  Serial.println(" cm");
  delay(200);
}

pulseIn()

Waits for a pin to go HIGH, times it, then returns duration in microseconds

delayMicroseconds()

Like delay() but in microseconds (µs) — much more precise for sensor pulses

Distance Alarm — Wiring

📡

HC-SR04

VCC→5V, GND→GND, TRIG→Pin 9, ECHO→Pin 10

🔴

Red LED

Anode → 220Ω → Pin 7, Cathode → GND

🟢

Green LED

Anode → 220Ω → Pin 6, Cathode → GND

🔊

Buzzer

Positive → Pin 5, Negative → GND

Logic: Distance > 30cm → green LED on, silent. Distance 10–30cm → orange warning. Distance < 10cm → red LED + buzzer alarm!

Full Code

Distance Alarm Code

const int trigPin=9, echoPin=10;
const int greenLed=6, redLed=7, buzzer=5;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(greenLed, OUTPUT);
  pinMode(redLed, OUTPUT);
  pinMode(buzzer, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  long dur = pulseIn(echoPin, HIGH);
  float dist = dur / 58.2;

  Serial.print("Distance: "); Serial.print(dist); Serial.println(" cm");

  if (dist < 10) {
    digitalWrite(redLed, HIGH); digitalWrite(greenLed, LOW);
    tone(buzzer, 1000);  // ALARM!
  } else if (dist < 30) {
    digitalWrite(redLed, HIGH); digitalWrite(greenLed, HIGH);
    noTone(buzzer);  // Warning zone
  } else {
    digitalWrite(greenLed, HIGH); digitalWrite(redLed, LOW);
    noTone(buzzer);  // All clear
  }
  delay(100);
}

Deep Dive

Understanding pulseIn()

What does pulseIn(pin, HIGH) do?

It watches the pin and waits for it to go HIGH. The moment it goes HIGH, it starts a timer. When the pin goes LOW again, it stops the timer and returns the time in microseconds.

Range

HC-SR04 can detect objects from 2 cm to 400 cm (about 13 feet)

Accuracy

Accurate to about ±3 mm — great for most robotics projects

Timeout

pulseIn() has a default timeout of 1 second. If nothing reflects, it returns 0

Formula check

Sound = 343 m/s = 0.0343 cm/µs. Round trip ÷ 2 → ÷ 58.2 = cm
