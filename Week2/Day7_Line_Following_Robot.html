The Sensors

IR Sensors for Line Detection

🔴

IR LED + Phototransistor

Each sensor emits IR light downward. Light reflects off white surfaces, barely reflects off black

⬜

White Surface

IR reflects back → sensor output = LOW (0) — "I see white/no line"

⬛

Black Line

IR absorbed → no reflection → sensor output = HIGH (1) — "I'm on the line!"

🤖

Two Sensors

Left sensor + Right sensor positioned to straddle the line. Use their states to steer!

Logic

The Navigation Truth Table

Left SensorRight SensorMeaningAction
LOW (0)LOW (0)Both on white → on track➡️ Go FORWARD
HIGH (1)LOW (0)Left on black → drifted left↪️ Turn RIGHT
LOW (0)HIGH (1)Right on black → drifted right↩️ Turn LEFT
HIGH (1)HIGH (1)Both on black → intersection➡️ Go FORWARD

This is reactive navigation — the robot constantly corrects itself based on sensor feedback. It's a simple but powerful form of autonomous control!

Full Code

Line Follower Program

// Motor A (Left)
const int in1=4,in2=5,ena=6;
// Motor B (Right)
const int in3=7,in4=8,enb=9;
// IR Sensors
const int leftSensor=2, rightSensor=3;
const int SPEED = 180;

void forward(){ digitalWrite(in1,HIGH);digitalWrite(in2,LOW);analogWrite(ena,SPEED);digitalWrite(in3,HIGH);digitalWrite(in4,LOW);analogWrite(enb,SPEED); }
void turnLeft(){ digitalWrite(in1,LOW);digitalWrite(in2,LOW);analogWrite(ena,0);digitalWrite(in3,HIGH);digitalWrite(in4,LOW);analogWrite(enb,SPEED); }
void turnRight(){ digitalWrite(in1,HIGH);digitalWrite(in2,LOW);analogWrite(ena,SPEED);digitalWrite(in3,LOW);digitalWrite(in4,LOW);analogWrite(enb,0); }
void stopAll(){ analogWrite(ena,0);analogWrite(enb,0); }

void setup() {
  pinMode(in1,OUTPUT);pinMode(in2,OUTPUT);pinMode(ena,OUTPUT);
  pinMode(in3,OUTPUT);pinMode(in4,OUTPUT);pinMode(enb,OUTPUT);
  pinMode(leftSensor,INPUT);pinMode(rightSensor,INPUT);
}

void loop() {
  int L = digitalRead(leftSensor);
  int R = digitalRead(rightSensor);
  if      (!L && !R) forward();    // On track
  else if ( L && !R) turnRight();  // Drifted left
  else if (!L &&  R) turnLeft();   // Drifted right
  else               forward();    // Intersection
}
Code Pattern

Writing Reusable Motor Functions

Why use functions?

forward(), turnLeft(), turnRight() — write once, call anywhere. Cleaner than copying 6 lines every time!

void functions

Functions that don't return a value use void. They just DO something (set pins, print, etc.)

Function parameters

Add a speed parameter: void forward(int speed) for more flexibility — use in Week 3!

Modular design

The same motor functions can be reused in Day 8's obstacle-avoiding robot. Write once, reuse everywhere!
