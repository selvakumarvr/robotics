# Arduino & Robotics Teaching Curriculum

A complete 12-week hands-on Arduino and Robotics course for young makers.

**Live site:** https://selvakumarvr.github.io/robotics/

## Course Structure

| Weeks | Level | Topics |
|-------|-------|--------|
| 1–8 | Beginner | Electronics, sensors, motors, IoT, displays, robotics |
| 9–12 | Intermediate | PCB design, soldering, Git/GitHub, portfolio |

- 12 Weeks · 96 Lessons · 12 Capstone Projects
- All lessons are self-contained HTML files — no server needed
- Reference PDFs and online resource links included

## Viewing Locally

Open `index.html` in any browser, or run a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`
