Slide 1 of 10 · Time without freezing

🕒 millis() — Do many things at once

delay() is easy, but it freezes your whole program. millis() is the grown-up way to track time and do many things in parallel.

What's the problem with delay()?

When you write delay(1000), the Arduino just stares at the wall for one whole second. It can't read a button, check a sensor, or do anything else.

The trick: ask "what time is it now?"

millis() returns how many milliseconds the board has been running. By remembering "the last time I did something", you can schedule tasks without ever waiting.

unsigned long lastBlink = 0;
const long interval = 500;  // blink every 500ms

void loop() {
  if (millis() - lastBlink >= interval) {
    lastBlink = millis();
    digitalWrite(LED, !digitalRead(LED));
  }
  // ← you can still read buttons / sensors here!
}

Make two LEDs blink at different speeds (say 300 ms and 800 ms) — impossible with delay(), trivial with millis(). This is your first real state machine.

Slide 2 of 10 · Arduino listens back

🔘 Buttons & switches — when Arduino reads YOU

An LED is Arduino telling you something. A button is YOU telling Arduino something. Mastering this opens the door to every interactive project.

The "floating pin" problem 👻

A pin that isn't connected to anything reads garbage — flips between HIGH and LOW randomly, like a ghost touching it. Buttons only connect when pressed, so the "not pressed" pin is floating.

The fix: a "pull-up" resistor 🪢

A 10 kΩ resistor between the pin and +5 V pulls the pin HIGH when nothing else is touching it. Press the button → the pin is yanked to GND (LOW). Easy.

Even better: Arduino has built-in pull-ups — just use pinMode(2, INPUT_PULLUP). No extra resistor needed!

void setup() {
  pinMode(2, INPUT_PULLUP);   // button
  pinMode(13, OUTPUT);        // LED
}
void loop() {
  // pressed = LOW (because pull-up makes it HIGH otherwise)
  if (digitalRead(2) == LOW) {
    digitalWrite(13, HIGH);
  } else {
    digitalWrite(13, LOW);
  }
}

🌀 INPUT (floating)

Random HIGH/LOW — avoid.

🔼 INPUT_PULLUP (use this)

Stable HIGH by default. Press = LOW.

Slide 3 of 10 · Debug like a pro

🖥️ Serial Monitor — Arduino's chat window

When your code doesn't work, the Serial Monitor lets you ASK Arduino what it's thinking — without opening it up or guessing.

What is it?

A little window in the Arduino IDE that prints whatever your sketch sends over the USB cable. Think of it as Arduino texting you.

void setup() {
  Serial.begin(9600);   // open the chat at 9600 baud
}

void loop() {
  int temp = analogRead(A0);
  Serial.print("Sensor says: ");
  Serial.println(temp);   // new line at the end
  delay(500);
}

Three tricks every maker learns

1. Baud rate must match: set the Monitor's dropdown to 9600 too, or you'll see gibberish.

2. println vs print: println adds a new line so output isn't one long blob.

3. Use it to debug: sprinkle Serial.println(...) through your code to find which line is misbehaving.

Print the value of a button + a sensor at the same time. Watch the numbers change in real time as you press and poke.

Your laptop receives whatever your sketch Serial.prints — and you can type back too.

Slide 4 of 10 · Arduino's senses

📡 Cool sensors — give Arduino superpowers

A microcontroller without sensors is just a flashing light. Plug in any of these little modules and Arduino can see, hear, smell, and feel the world.

📏
HC-SR04
Ultrasonic — measures distance with sound waves (like a bat)
🌡️
DHT22 / DHT11
Temperature & humidity in one chip
🌑
PIR
Motion sensor — detects warm bodies (people, pets)
☀️
LDR
Light sensor — its resistance drops in bright light
📺
IR receiver
Reads codes from any TV remote
🧭
MPU-6050
Tilt + acceleration — for self-balancing robots

The rule of thumb 👍

Most sensors plug into analog pins (LDR, soil) or use a library (HC-SR04, DHT, IR, MPU). Read the module's datasheet — every one has a 5-minute "Hello World" sketch on Arduino-tutorials sites.

// HC-SR04 — how far is something?
const int trig = 9, echo = 10;

void setup() {
  Serial.begin(9600);
  pinMode(trig, OUTPUT);
  pinMode(echo, INPUT);
}
void loop() {
  digitalWrite(trig, LOW);  delayMicroseconds(2);
  digitalWrite(trig, HIGH); delayMicroseconds(10);
  digitalWrite(trig, LOW);

  long us = pulseIn(echo, HIGH);
  float cm = us * 0.0343 / 2;   // speed of sound

  Serial.print("Distance: ");
  Serial.println(cm);
  delay(200);
}

Hook up an HC-SR04, point it at a wall, and walk towards it. Watch the number drop in Serial Monitor. Now make an LED brighter when you get closer!

Slide 5 of 10 · Make things MOVE

🤖 Servos & motors — Arduino in motion

Light is cool. Movement is COOL+. Three families of motors, each great at a different job — pick the right one for the project.

🦾 Servo motor — precise angles

Turns to an exact angle (0–180°) and holds. Perfect for robot arms, steering, opening doors. Powered straight from 5 V on small servos (SG-90).

🛞 DC motor — spin spin spin

Plain spinning. Cheap. Needs an H-bridge chip (L298N or L293D) so Arduino can control speed AND direction without frying itself.

🪛 Stepper motor — count the steps

Moves in tiny precise "steps" — used in 3D printers and CNC machines. Heavier on wiring; great when you need micrometer accuracy.

⚠ Rule #1: Arduino doesn't power motors directly!

Even a small DC motor pulls way more current than a pin can deliver. Always use a driver chip (or relay) and a separate battery for the motor.

// Sweep a servo back and forth
#include <Servo.h>
Servo arm;

void setup() {
  arm.attach(9);   // servo signal on pin 9
}
void loop() {
  for (int a = 0; a <= 180; a++) {
    arm.write(a);
    delay(15);
  }
  for (int a = 180; a >= 0; a--) {
    arm.write(a);
    delay(15);
  }
}

Connect an SG-90 servo's signal wire to D9. Run the code above. Watch the arm wave. Now make it wave only when a button is pressed!

Slide 6 of 10 · Make some noise

🔊 Buzzers & melodies — Arduino sings

A buzzer + the tone() function = an instant beep, alarm, doorbell, or full melody. The cheapest, most fun output you can add.

Active vs passive buzzers

Active buzzer: a chip inside makes a fixed beep when you give it power. Lazy and loud.

Passive buzzer: a tiny speaker — YOU control the pitch by feeding it different frequencies with tone(). This is the one you want.

// 4-note jingle
const int spk = 8;
int notes[]   = { 262, 294, 330, 349 };  // C4 D4 E4 F4 (Hz)
int dur[]     = { 300, 300, 300, 600 };  // ms each

void setup() {
  for (int i = 0; i < 4; i++) {
    tone(spk, notes[i], dur[i]);
    delay(dur[i] + 50);
  }
  noTone(spk);
}
void loop() {}

Add a button. Each press → next note in an array. Build your own little piano!

Pro tip 🎼

Note frequencies for one octave: C4=262, D4=294, E4=330, F4=349, G4=392, A4=440, B4=494, C5=523. Use these in arrays to compose anything.

Slide 7 of 10 · Give Arduino a screen

📺 Tiny screens — OLED & LCD

Stop relying on the Serial Monitor — let your project show its own readings on a screen. A 0.96″ OLED costs less than $3 and looks fantastic.

The magic word: I²C

I²C ("eye-squared-see") is a way for chips to talk over just two wires — SDA (data) and SCL (clock). Many sensors and almost every small OLED screen use it. You can chain multiple devices on the same pair of wires!

⬛
0.96″ OLED
128×64 pixels — sharp + crisp, no backlight, ~$3
🔲
16×2 LCD
Classic blue/green character display, ~$4 with I²C backpack
🟦
TFT 1.8″
Full colour 128×160 — for fancier dashboards, ~$6
#include <Adafruit_SSD1306.h>
Adafruit_SSD1306 oled(128, 64, &Wire);

void setup() {
  oled.begin(SSD1306_SWITCHCAPVCC, 0x3C);
  oled.setTextSize(2);
  oled.setTextColor(WHITE);
}
void loop() {
  oled.clearDisplay();
  oled.setCursor(0, 10);
  oled.print("Hi Maker!");
  oled.display();
  delay(500);
}

Wire an OLED, then show your HC-SR04 distance reading from Slide 4 right on the screen — no laptop required. Instant portable gadget!

Slide 8 of 10 · Light shows

🌈 NeoPixels — addressable light magic

WS2812 LEDs (everyone calls them "NeoPixels") let you control HUNDREDS of full-colour LEDs with just ONE Arduino pin. Yes, really.

What makes them special?

Each LED has a tiny chip inside that listens for its own colour command, then passes the rest of the message along to the next LED. Chain them, and you can paint any pattern across the whole strip.

#include <Adafruit_NeoPixel.h>
#define PIN  6
#define N    16

Adafruit_NeoPixel strip(N, PIN, NEO_GRB + NEO_KHZ800);

void setup() { strip.begin(); strip.show(); }

void loop() {
  for (int i = 0; i < N; i++) {
    // rainbow: hue 0..65535 around the wheel
    int hue = (i * 65536L) / N + millis() * 3;
    strip.setPixelColor(i, strip.ColorHSV(hue));
  }
  strip.show();
  delay(20);
}

16-LED ring + the code above = an infinity rainbow. Now make it react to sound (mic module) or distance (HC-SR04) for a music-visualiser.

Slide 9 of 10 · Off the laptop

🔋 Going untethered — power, soldering & cases

A breadboard tied to your laptop is fine for learning. To make a REAL project you can carry around, demo, or gift — you need batteries, solder, and a case.

🔋 Powering Arduino without USB

9 V battery → barrel jack: easy but doesn't last long. Good for one-off demos.

4 × AA pack (~6 V): goes into the barrel jack — lasts much longer.

USB power bank: the cheapest "long battery" — just plugs into the USB port.

LiPo cell (3.7 V) + boost: slimmest and rechargeable; needs a TP4056 charge module.

🔥 Soldering basics

Iron tip in first, then solder. Touch the iron to the joint for ~2 seconds, then melt a tiny bit of solder onto the joint (not the iron). A good joint is shiny, not blobby.

Always: safety glasses, ventilation, sponge to clean the tip, and never touch the metal end.

🎛️ From breadboard → perfboard

A perfboard looks like a breadboard but each hole is its own copper pad. Solder your components in place, run thin wires under the board — your project is now permanent.

Bigger leap: design a real PCB with free tools like KiCad or EasyEDA. Send the file to JLCPCB and 10 PCBs ship to your door for ~$5.

📦 Cases & enclosures

Free: cardboard box + hot-glue (seriously, looks great in demos).

Mid: off-the-shelf plastic project boxes (~$3).

Pro: 3D-printed shell — sketch in Tinkercad (free, browser-based), print at a library makerspace.

Take ONE of your breadboard projects and move it to perfboard + a battery + a cardboard case. Suddenly it's not a gadget on your desk — it's a product you can show off.
