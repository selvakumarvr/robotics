Electronics
Basics

Understanding electricity, components, and how circuits work

What is Electronics?

Electronics is all about controlling the flow of electricity to make things happen — lights turn on, motors spin, screens display images.

You're surrounded by electronics every day: your phone, game controllers, headphones, even your fridge. They all use tiny circuits to work!

Think of it like plumbing: Electricity flows through wires like water flows through pipes. Components like resistors and LEDs are like valves and faucets.

⚡

Everything electronic starts with controlling electricity

The Big Three: V, I, R

V

Voltage

The "pressure" pushing electricity through a circuit. Measured in Volts (V).

💧 Like water pressure in a pipe

I

Current

The "flow" of electricity — how much charge moves per second. Measured in Amps (A).

🌊 Like how much water flows

R

Resistance

How much a component "resists" the flow. Measured in Ohms (Ω).

🚰 Like a narrow pipe slowing flow

Ohm's Law — The Golden Rule

V = I × R

V

Voltage (Volts)

I

Current (Amps)

R

Resistance (Ohms)

Example: An LED needs 2V and 20mA. Your Arduino gives 5V. What resistor do you need?

R = (5V − 2V) / 0.02A = 150Ω

Key Components: Resistors & LEDs

Resistors

Resist the flow of electrical energy, controlling voltage and current. Colored stripes show their value.

Brown Black Orange Gold

= 10,000Ω (10kΩ) ±5%

LEDs

Light Emitting Diodes glow when electricity passes through. Current only flows one way!

🔴 🟢 🔵 🟡

Long leg (+) = Anode → connect to power
Short leg (−) = Cathode → connect to ground

⚠️ Important: Always use a resistor with an LED! Without one, too much current flows and the LED burns out.

Key Components: Capacitors & Transistors

Capacitors

Store and release electrical energy — like tiny rechargeable batteries. Used to smooth out voltage fluctuations.

  • Ceramic caps — small, no polarity
  • Electrolytic caps — larger, have + and − sides
  • Measured in Farads (usually µF or pF)

Transistors

Electronic switches — a small current on one pin controls a larger current through the other pins.

  • 3 legs: Base, Collector, Emitter
  • Control motors, relays, and high-power devices
  • Building block of all modern computers!

Sensors — Eyes & Ears of Your Project

Sensors convert physical things (light, heat, motion) into electrical signals your Arduino can read.

🌡️

Temperature (TMP36)

Outputs voltage based on temperature. Center pin gives the reading.

💡

Light (LDR / Photoresistor)

Resistance changes with light — bright = low resistance, dark = high.

📡

Ultrasonic (HC-SR04)

Sends sound pulses and measures the echo to find distance.

🔘

Push Button

Simple ON/OFF switch. Closes a circuit when pressed.

🎚️

Potentiometer

Variable resistor with a knob. Turn it to change voltage output.

📐

Tilt Sensor

A metal ball inside that detects orientation changes.

Actuators — Making Things Move & Sound

Actuators convert electrical signals back into physical action: movement, light, or sound.

⚙️

DC Motor

Spins continuously. Speed controlled by voltage. Needs a transistor/H-bridge to drive.

🔄

Servo Motor

Rotates to a precise angle (0°–180°). Controlled by PWM pulses from Arduino.

🔊

Piezo Buzzer

Vibrates to make sound. Can play tones and simple melodies!

The Breadboard — Your Circuit Playground

A breadboard lets you build circuits without soldering. Just plug in wires and components!

How It's Connected Inside:

  • Power rails (+ and −) run the full length, top & bottom
  • Rows (a–e, f–j) are connected horizontally in groups of 5
  • The center gap separates the two halves

Pro tip: Always connect the Arduino's 5V to the + rail and GND to the − rail first!

Meet Arduino

The tiny computer that makes things interactive

What is Arduino?

Arduino is a small, affordable microcontroller board that you can program to read sensors and control actuators.

The 3-Part System

  • Sensors listen to the physical world (input)
  • Microcontroller decides what to do (brain)
  • Actuators take action (output)

Fun fact: Arduino is open-source! Anyone can see the designs and build their own version.

🤖

Arduino Uno — the most popular board for beginners

Arduino Uno — Parts Explained

🔌 USB Port

Upload code and power the board from your computer

⚡ Power Pins

5V and GND pins provide power to your circuits

📍 Digital Pins (0–13)

Read/write HIGH or LOW. Pins with ~ support PWM (analog-like output)

📊 Analog Pins (A0–A5)

Read varying voltage (0–5V) as values 0–1023

🧠 ATmega328P

The microcontroller chip — the brain that runs your code

🔄 Reset Button

Restarts your program from the beginning

Setting Up Arduino IDE

The Arduino IDE is the software where you write and upload code to your board.

1

Download the IDE

Go to arduino.cc/en/software and download for your OS

2

Connect Your Board

Plug the Arduino into your computer via USB. The green power LED should turn on.

3

Select Board & Port

Go to Tools → Board → Arduino Uno and Tools → Port → select your Arduino

4

Test with Blink

Go to File → Examples → 01.Basics → Blink and click the Upload button ➜

Arduino Code Structure

Every Arduino program (called a "sketch") has two main functions:

sketch.ino
// Runs ONCE when Arduino starts void setup() { // Initialize pins, serial, etc. pinMode(13, OUTPUT); } // Runs FOREVER in a loop void loop() { // Your main code here digitalWrite(13, HIGH); delay(1000); digitalWrite(13, LOW); delay(1000); }

setup()

Runs once at startup. Use it to set pin modes, start serial communication, etc.

loop()

Runs over and over forever. This is where your main logic goes.

Key Functions

pinMode() · digitalWrite() · digitalRead() · analogRead() · delay()

Digital vs Analog Signals

Digital ON / OFF

Only two states: HIGH (5V) or LOW (0V)

// Read a button int state = digitalRead(2); // Write to LED digitalWrite(13, HIGH);

Think: Light switch — ON or OFF

Analog Range

Range of values: 0 to 1023 (input) or 0 to 255 (output/PWM)

// Read sensor (0-1023) int val = analogRead(A0); // Write brightness (0-255) analogWrite(9, 128);

Think: Dimmer switch — any brightness

Using Tinkercad

Build and simulate circuits online — no hardware needed!

What is Tinkercad Circuits?

Tinkercad is a free online tool by Autodesk that lets you design and simulate Arduino circuits in your browser.

Why Use Tinkercad?

  • Free — no cost, just a browser
  • Safe — can't burn out real components!
  • Visual — see current flow in real time
  • Code — write & test Arduino code online
  • Share — share designs with classmates
💻

tinkercad.com/circuits

Works in Chrome, Firefox, Edge — no install needed

Getting Started with Tinkercad

1

Create a Free Account

Go to tinkercad.com → Sign up (use your school/personal email)

2

Open Circuits

Click "Circuits" from the left sidebar, then "Create new Circuit"

3

Drag Components

From the right panel, search and drag: Arduino Uno, Breadboard, LEDs, Resistors, etc.

4

Wire Everything Up

Click on a pin/hole and drag to another pin/hole to create a wire. Color-code: red = power, black = ground

5

Write Code & Simulate

Click "Code" to open the editor, write your Arduino sketch, then hit "Start Simulation"

Tinkercad Interface Tour

🎨 Workspace (Center)

The main area where you build your circuit. Drag, rotate, and connect components here.

📦 Component Panel (Right)

Search bar + categories. Find Arduino, resistors, LEDs, sensors, and more. Use "All" for full list.

💻 Code Editor (Top)

Switch between Blocks (Scratch-like), Blocks + Text, or Text (full Arduino code).

▶️ Simulation Controls (Top)

Start Simulation runs your circuit. Serial Monitor shows debug output. Stop anytime.

💡 Tip: Use "Blocks + Text" mode when learning — it shows blocks AND the generated Arduino code side-by-side!

Project 1: LED Blink

BEGINNER

The "Hello World" of Arduino! Make an LED turn on and off.

Blink.ino
void setup() { pinMode(13, OUTPUT); } void loop() { digitalWrite(13, HIGH); delay(1000); // ON 1 sec digitalWrite(13, LOW); delay(1000); // OFF 1 sec }

Circuit Wiring

  • LED long leg → 220Ω resistor → Pin 13
  • LED short leg → GND

🎯 Try This!

Change the delay to 200 for fast blink, or 2000 for slow. Try different pins!

Project 2: Traffic Light

BEGINNER

Control 3 LEDs to simulate a real traffic light sequence.

TrafficLight.ino
int red = 4, yellow = 3, green = 2; void setup() { pinMode(red, OUTPUT); pinMode(yellow, OUTPUT); pinMode(green, OUTPUT); } void loop() { digitalWrite(green, HIGH); delay(5000); digitalWrite(green, LOW); digitalWrite(yellow, HIGH); delay(2000); digitalWrite(yellow, LOW); digitalWrite(red, HIGH); delay(5000); digitalWrite(red, LOW); }

🚦 Wiring

  • Red LED → 220Ω → Pin 4
  • Yellow LED → 220Ω → Pin 3
  • Green LED → 220Ω → Pin 2
  • All cathodes → GND

🎯 Challenge

Add a pedestrian button that triggers the red light!

Project 3: Temperature Monitor

INTERMEDIATE

Read temperature from a TMP36 sensor and display it on the Serial Monitor.

TempMonitor.ino
void setup() { Serial.begin(9600); } void loop() { int reading = analogRead(A0); float voltage = reading * 5.0 / 1024.0; float tempC = (voltage - 0.5) * 100; Serial.print("Temp: "); Serial.print(tempC); Serial.println(" C"); delay(1000); }

🌡️ TMP36 Wiring

  • Left pin → 5V
  • Center pin → A0 (analog read)
  • Right pin → GND

How It Works

TMP36 outputs voltage proportional to temperature. We convert the analog reading (0–1023) to voltage, then to °C.

Project 4: Distance Sensor

INTERMEDIATE

Use the HC-SR04 ultrasonic sensor to measure distance like a bat!

Distance.ino
int trigPin = 9, echoPin = 10; void setup() { pinMode(trigPin, OUTPUT); pinMode(echoPin, INPUT); Serial.begin(9600); } void loop() { digitalWrite(trigPin, LOW); delayMicroseconds(2); digitalWrite(trigPin, HIGH); delayMicroseconds(10); digitalWrite(trigPin, LOW); long dur = pulseIn(echoPin,HIGH); float cm = dur * 0.034 / 2; Serial.println(cm); delay(500); }

📡 How Ultrasonic Works

Sends a sound pulse → waits for echo → calculates distance from time. Speed of sound = 343 m/s.

Wiring

VCC → 5V • GND → GND • Trig → Pin 9 • Echo → Pin 10

Project 5: Smart Night Light

INTERMEDIATE

LED turns on automatically when it's dark using a photoresistor (LDR).

NightLight.ino
int ldrPin = A0; int ledPin = 9; int threshold = 400; void setup() { pinMode(ledPin, OUTPUT); Serial.begin(9600); } void loop() { int light = analogRead(ldrPin); Serial.println(light); if (light < threshold) { digitalWrite(ledPin, HIGH); } else { digitalWrite(ledPin, LOW); } delay(200); }

💡 How LDR Works

Photoresistors change resistance based on light. Bright light = low resistance, darkness = high resistance.

Wiring

LDR → one side to 5V, other to A0 + 10kΩ resistor to GND (voltage divider)

Project 6: Servo Sweep

ADVANCED

Control a servo motor to sweep back and forth, or use a potentiometer to set the angle.

ServoControl.ino
#include <Servo.h> Servo myServo; int potPin = A0; void setup() { myServo.attach(9); } void loop() { int val = analogRead(potPin); int angle = map(val,0,1023,0,180); myServo.write(angle); delay(15); }

🔄 Servo Wiring

Red wire → 5V • Brown → GND • Orange → Pin 9

New Concepts

#include — importing a library
map() — converts one range to another (0–1023 → 0–180°)

Project 7: LCD + Sensor Display

ADVANCED

Show temperature on an LCD screen — a real-world monitoring system!

LCDTemp.ino
#include <LiquidCrystal.h> LiquidCrystal lcd(12,11,5,4,3,2); void setup() { lcd.begin(16, 2); lcd.print("Temp Monitor"); } void loop() { int val = analogRead(A0); float v = val * 5.0 / 1024.0; float c = (v - 0.5) * 100; lcd.setCursor(0, 1); lcd.print(c); lcd.print(" C "); delay(1000); }

🖥️ LCD (16x2)

16 characters wide, 2 rows. Uses 6 Arduino pins. Available in Tinkercad!

🎯 Challenge

Add a warning LED that turns on when temp > 30°C. Show both °C and °F!

Debugging Tips — When Things Don't Work

🔌 Check Your Wiring

Loose wires are the #1 issue. Make sure connections are firm and in the right holes.

🔋 Verify Power

Is 5V connected to +rail? GND to −rail? Is the USB plugged in?

📺 Use Serial Monitor

Add Serial.println() to see what values your code is actually reading.

🔄 Check Polarity

LEDs, electrolytic capacitors, and diodes have a + and − side. Flip them if they don't work.

Golden rule: If it doesn't work in Tinkercad, it won't work in real life either. Debug virtually first, then build physically!

Test & Iterate

If something doesn't work, compare your real circuit to the Tinkercad diagram. Debug step by step!
